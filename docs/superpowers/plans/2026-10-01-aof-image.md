# AOFImage and the Image API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Images are managed through the API in batches, stored once in MinIO, and shown by every App through `AOFImage`, resized and converted by each App's Next optimizer.

**Status:** implemented (uncommitted) @ 2026-10-02T08:43:54Z — Task 8 (Laura) skipped by request

**Architecture:** `packages/storage` prepares an upload with sharp (orient, strip metadata, cap 2560px, WebP, 16px blur) and writes it to the public `images` bucket. `image."Image"` rows (shared schema, ADR 0013) hold dimensions, blur and per-language alt. `apps/api` serves `/v1/images` (batch writes, all-or-nothing). Each App rewrites `/images/*` to MinIO and renders with `AOFImage`, a typed wrapper over `next/image`. Laura's Photo, Favorite and quiz image columns are dropped with the code that used them.

**Tech Stack:** Next.js 16.3.6 (`next/image`), sharp, `@aws-sdk/client-s3` against MinIO, Hono + hono-openapi + `@hono/standard-validator`, zod 4, Prisma 6 (multi-schema) with Liquibase changesets, Vitest with globals.

**Spec:** `docs/superpowers/specs/2026-10-01-aof-image-design.md` (decisions), `docs/adr/0013-images-live-in-a-shared-image-schema.md` (why).

## Global Constraints

- Every test file's first line is `// @module-tag unit` or `// @module-tag integration`; integration files are named `*.integration.test.ts`. Vitest globals, no `from "vitest"` import.
- Never call `Object.keys/values/entries/fromEntries`; use `objectKeys`, `objectValues`, `objectEntries`, `objectFromEntries` from `@allonfire/utils/helpers/object`.
- No `as` casts: narrow, zod-parse, `as const satisfies`.
- A constant's type comes from zod (`z.enum(X)` then `z.infer`); lookup tables are `as const satisfies Record<K, V>`.
- Package exports mirror the file path, one key per file: `"./features/image/prepare-image": "./src/features/image/prepare-image.ts"`.
- Database changes: edit `.prisma`, `pnpm db:changeset <name>`, review the SQL, `pnpm db:update`, `pnpm db:drift`. Never `prisma db push` or `prisma migrate`. Never edit an applied changeset.
- Enum values (`Role.ADMIN`, `AllowedApp.ALL`) come from `@allonfire/database/enums`.
- API errors are RFC 9457 problems through `problemResponse` or a thrown `HTTPException`; guards come from `@allonfire/auth/features/guards/middleware/*`.
- API routes are chained (`new Hono().get(...).post(...)`); handlers built with `createFactory<AppBindings>().createHandlers(...)`.
- Never add a `biome-ignore` comment without asking the user first.
- No commits: the user reviews and commits. End every task with `pnpm biome check --write <touched files>` (scoped, never repo-wide).
- Limits: 20 MiB per file, 100 MiB per upload request, 20 files per upload, 100 items per PATCH or DELETE, Images capped at 2560px, WebP quality 90, blur 16px wide.

## Review Focus

- **One file uploaded:** `parseBody({ all: true })` returns a single `File`, not an array, when one `file` part is sent; the batch of one must work. Pinned in Task 6.
- **Phone photo taken sideways:** EXIF orientation 6 must come out upright with width and height swapped, since metadata is stripped afterwards. Pinned in Task 2.
- **Same id twice in a batch:** `PATCH` or `DELETE` listing an id twice must not answer 404 because fewer rows matched than ids were sent. Pinned in Task 3.
- **A User of another App:** `GET /v1/images?app=laura` from a User allowed only elsewhere is 403, while an `ALL` Image by id is readable by any signed-in User. Pinned in Task 5.
- **Upload fails half-way:** when the row insert fails, every object already put is deleted and the error still reaches `onError` as a 500. Pinned in Task 6.

```ts
 * that path. A relative `src` is fetched in-process, so Next 16's block on
 * private-IP upstreams (MinIO on the Docker network) never applies.

const imageConfig = (origin: string, config: NextConfig): NextConfig => {

    source: `${IMAGE_PATH}/:path*`,

      minimumCacheTTL: IMAGE_CACHE_TTL_SECONDS,

      const own = (await config.rewrites?.()) ?? [];
      return Array.isArray(own)
        ? [imageRewrite, ...own]
        : { ...own, afterFiles: [imageRewrite, ...own.afterFiles] };
    },
  };
};
```

```ts
import sharp, { type Metadata } from "sharp";

/** Longest side an Image is stored at; the optimizer never needs more. */
export const MAX_IMAGE_DIMENSION = 2560;
/** The stored file is the optimizer's source, so it keeps near-full quality. */
const SOURCE_QUALITY = 90;
/** Next recommends a placeholder of 10px or less; 16px keeps a little shape. */
const BLUR_WIDTH = 16;
const BLUR_QUALITY = 50;

export type PreparedImage = {
  buffer: Buffer;
  width: number;
  height: number;
  bytes: number;
  /** `data:image/webp;base64,...`, ready for next/image's `blurDataURL`. */
  blurDataUrl: string;
};

/** Not JPEG, PNG, WebP or AVIF, or bytes sharp cannot decode. */
export class UnsupportedImageError extends Error {
  constructor(cause?: unknown) {
    super("Unsupported image", { cause });
    this.name = "UnsupportedImageError";
  }
}

// AVIF and HEIC are both `heif`; only AV1 compression is AVIF, and the
// prebuilt sharp cannot decode HEIC anyway.
const isAccepted = ({ format, compression }: Metadata): boolean =>
  format === "jpeg" ||
  format === "png" ||
  format === "webp" ||
  (format === "heif" && compression === "av1");

/**
 * Upright, metadata-free WebP capped at `MAX_IMAGE_DIMENSION`, plus its blur.
 * `.rotate()` applies the EXIF orientation first; sharp then writes no
 * metadata unless asked, so GPS and camera data never reach the bucket.
 */
export async function prepareImage(input: Buffer): Promise<PreparedImage> {
  try {
    const metadata = await sharp(input).metadata();
    if (!isAccepted(metadata)) {
      throw new UnsupportedImageError();
    }
    const source = sharp(input, { failOn: "truncated" }).rotate();
    const [{ data, info }, blur] = await Promise.all([
      source
        .clone()
        .resize({
          fit: "inside",
          height: MAX_IMAGE_DIMENSION,
          width: MAX_IMAGE_DIMENSION,
          withoutEnlargement: true,
        })
        .webp({ quality: SOURCE_QUALITY })
        .toBuffer({ resolveWithObject: true }),
      source
        .clone()
        .resize({ width: BLUR_WIDTH })
        .webp({ quality: BLUR_QUALITY })
        .toBuffer(),
    ]);
    return {
      blurDataUrl: `data:image/webp;base64,${blur.toString("base64")}`,
      buffer: data,
      bytes: info.size,
      height: info.height,
      width: info.width,
    };
  } catch (error) {
    throw error instanceof UnsupportedImageError
      ? error
      : new UnsupportedImageError(error);
  }
}
```

```ts
const IMAGE_CONTENT_TYPE = "image/webp";

export async function putImageObject(key: string, body: Buffer): Promise<void> {
  await s3.send(
    new PutObjectCommand({
      Body: body,
      Bucket: IMAGE_BUCKET,
      CacheControl: `public, max-age=${IMAGE_CACHE_TTL_SECONDS}, immutable`,
      ContentType: IMAGE_CONTENT_TYPE,
      Key: key,
    })
  );
```

```ts
import { LANGUAGES } from "@allonfire/utils/constants/locales";
import { objectFromEntries } from "@allonfire/utils/helpers/object";
import { z } from "zod";
import type { Image } from "../../../generated/prisma/client";
import { AllowedApp } from "../../../generated/prisma/enums";
import { prisma } from "../prisma/client";

/** Screen readers read alt aloud; past a sentence or two it belongs in a caption. */
const MAX_ALT_LENGTH = 300;

/** Every Language must be present; an empty string marks a decorative Image. */
export const imageAltSchema = z.object(
  objectFromEntries(
    LANGUAGES.map((language) => [language, z.string().max(MAX_ALT_LENGTH)] as const)
  )
);
export type ImageAlt = z.infer<typeof imageAltSchema>;

export type ImageRecord = Omit<Image, "alt"> & { alt: ImageAlt };
export type NewImage = Omit<ImageRecord, "id" | "createdAt">;
export type ImageChange = {
  id: string;
  app?: AllowedApp | undefined;
  alt?: ImageAlt | undefined;
};

export class ImageNotFoundError extends Error {
  readonly ids: string[];
  constructor(ids: string[]) {
    super(`Unknown Image ids: ${ids.join(", ")}`);
    this.name = "ImageNotFoundError";
    this.ids = ids;
  }
}

// `alt` is a Json column; parsing narrows it instead of casting.
const toRecord = (row: Image): ImageRecord => ({
  ...row,
  alt: imageAltSchema.parse(row.alt),
});

type Transaction = Parameters<Parameters<typeof prisma.$transaction>[0]>[0];

/** Throws unless every id exists; duplicates in `ids` count once. */
async function assertAllExist(tx: Transaction, ids: readonly string[]) {
  const unique = [...new Set(ids)];
  const found = await tx.image.findMany({
    select: { id: true, key: true },
    where: { id: { in: unique } },
  });
  const foundIds = new Set(found.map(({ id }) => id));
  const missing = unique.filter((id) => !foundIds.has(id));
  if (missing.length > 0) {
    throw new ImageNotFoundError(missing);
  }
  return found;
}

export async function createImages(images: NewImage[]): Promise<ImageRecord[]> {
  const rows = await prisma.$transaction(
    images.map((data) => prisma.image.create({ data }))
  );
  return rows.map(toRecord);
}

/** The App's Images and the ALL ones, newest first; `cursor` is the last id seen. */
export async function listImages({
  app,
  cursor,
  limit,
}: {
  app: AllowedApp;
  cursor?: string | undefined;
  limit: number;
}): Promise<ImageRecord[]> {
  const rows = await prisma.image.findMany({
    orderBy: [{ createdAt: "desc" }, { id: "desc" }],
    take: limit,
    where: { app: { in: [app, AllowedApp.ALL] } },
    ...(cursor && { cursor: { id: cursor }, skip: 1 }),
  });
  return rows.map(toRecord);
}

export async function getImage(id: string): Promise<ImageRecord | null> {
  const row = await prisma.image.findUnique({ where: { id } });
  return row && toRecord(row);
}

/** All or nothing: an unknown id rolls the whole batch back. */
export function updateImages(changes: ImageChange[]): Promise<ImageRecord[]> {
  return prisma.$transaction(async (tx) => {
    await assertAllExist(
      tx,
      changes.map(({ id }) => id)
    );
    const rows = await Promise.all(
      changes.map(({ id, app, alt }) =>
        tx.image.update({
          data: { ...(app && { app }), ...(alt && { alt }) },
          where: { id },
        })
      )
    );
    return rows.map(toRecord);
  });
}

/** All or nothing; returns the deleted keys so the caller removes the files. */
export function deleteImages(ids: string[]): Promise<string[]> {
  return prisma.$transaction(async (tx) => {
    const found = await assertAllExist(tx, ids);
    await tx.image.deleteMany({ where: { id: { in: ids } } });
    return found.map(({ key }) => key);
  });
}
```

```ts
/** 413 naming the limit that was actually crossed, not the API-wide one. */
const tooLarge = (c: Context, limit: number) =>
  problemResponse(c, {
    code: ERROR_CODE.PAYLOAD_TOO_LARGE,
    detail: translate(ERROR_CODE.PAYLOAD_TOO_LARGE, localeOf(c), { limit }),
    status: HTTP_STATUS.PAYLOAD_TOO_LARGE,
  });

/** The service's unknown-id error, as the 404 every other route answers. */
const notFoundOnUnknownIds = (error: unknown): never => {
  throw error instanceof ImageNotFoundError
    ? new HTTPException(HTTP_STATUS.NOT_FOUND)
    : error;
};

export const uploadHandlers = (deps: ImageDeps) =>
  factory.createHandlers(
    uploadRoute,
    requireRole(Role.ADMIN),
    bodyLimit({ maxSize: MAX_UPLOAD_BYTES, onError: (c) => tooLarge(c, MAX_UPLOAD_BYTES) }),
    async (c) => {
      const form = await c.req.parseBody({ all: true });
      // One `file` part parses to a File, several to an array.
      const parsed = uploadFormSchema.safeParse({
        file: [form.file].flat(),
        meta: form.meta,
      });
      if (!parsed.success) {
        return validationHook({ error: parsed.error.issues, success: false }, c);
      }
      const { file: files, meta } = parsed.data;
      if (files.some((file) => file.size > MAX_FILE_BYTES)) {
        return tooLarge(c, MAX_FILE_BYTES);
      }

      // One at a time: sharp decodes the whole image, and the VPS has no swap.
      const prepared: PreparedImage[] = [];
      for (const file of files) {
        try {
          prepared.push(await deps.prepare(Buffer.from(await file.arrayBuffer())));
        } catch (error) {
          throw error instanceof UnsupportedImageError
            ? new HTTPException(HTTP_STATUS.UNSUPPORTED_MEDIA_TYPE)
            : error;
        }
      }

      const keys = prepared.map(() => `${randomUUID()}${IMAGE_EXTENSION}`);
      const uploadedBy = c.get(AUTH_VAR.SESSION).user.id;
      try {
        await Promise.all(
          prepared.map((image, index) => deps.putObject(keys[index] ?? "", image.buffer))
        );
        const images = await deps.createImages(
          prepared.map(({ blurDataUrl, bytes, height, width }, index) => ({
            alt: meta[index]?.alt ?? { en: "", it: "" },
            app: meta[index]?.app ?? AllowedApp.ALL,
            blurDataUrl,
            bytes,
            height,
            key: keys[index] ?? "",
            uploadedBy,
            width,
          }))
        );
        return c.json(images.map(toImageBody), HTTP_STATUS.CREATED);
      } catch (error) {
        // ponytail: best effort. An object left behind is invisible (no row
        // points at it); a failed cleanup must not hide the original error.
        await deps.deleteObjects(keys).catch((cleanup: unknown) =>
          logger.warn({ err: cleanup, keys }, "image cleanup failed")
        );
        throw error;
      }
    }
  );

  factory.createHandlers(

    requireRole(Role.ADMIN),
    sValidator("json", patchBodySchema, validationHook),
```

```tsx
import { IMAGE_PATH } from "@allonfire/utils/constants/images";
import type { Language } from "@allonfire/utils/constants/locales";
import Image, { type ImageProps } from "next/image";

/** What AOFImage reads from an API Image: enough to size, blur and describe it. */
export type AOFImageSource = {
  key: string;
  width: number;
  height: number;
  alt: Record<Language, string>;
  blurDataUrl: string;
};

/** The props AOFImage sets itself, from the Image or from `lcp`. */
type OwnedProps =
  | "alt"
  | "blurDataURL"
  | "fetchPriority"
  | "fill"
  | "height"
  | "loading"
  | "placeholder"
  | "preload"
  | "priority"
  | "sizes"
  | "src"
  | "width";

export type AOFImageProps = Omit<ImageProps, OwnedProps> & {
  image: AOFImageSource;
  /** The page's language; picks the alt. */
  language: Language;
  /** Required: without it the browser assumes the Image fills the viewport. */
  sizes: string;
  /**
   * The page's Largest Contentful Paint Image: fetched first and never lazy.
   * At most one per page. Next 16 prefers this over `preload`/`priority`.
   */
  lcp?: boolean;
};

export const AOFImage = ({
  image,
  language,
  lcp = false,
  ...props
}: AOFImageProps) => (
  <Image
    {...props}
    alt={image.alt[language]}
    blurDataURL={image.blurDataUrl}
    fetchPriority={lcp ? "high" : "auto"}
    height={image.height}
    loading={lcp ? "eager" : "lazy"}
    placeholder="blur"
    src={`${IMAGE_PATH}/${image.key}`}
    width={image.width}
  />
);
```
