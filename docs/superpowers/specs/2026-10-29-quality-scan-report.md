# Quality scan report: the workspace

Spec: `docs/superpowers/specs/2026-10-29-quality-scan-design.md` ·
Plan: `docs/superpowers/plans/2026-10-29-chore-quality-scan.md`

The report only describes problems; it fixes none of them. Pick what to
fix, and the fixes get their own plan.

## Method

- **Tree:** taken at HEAD `24015d1`, plus the uncommitted Edit User work
  as it stood (58 changed paths). Findings in those files are tagged
  **in progress**; their lines can move as that work changes.
- **Coverage:** every file was read.
  - 809 files across 8 areas: api 97, back-office 174, auth 77,
    storage 67, database 64, core 113, ui 114, config/design/root 53.
  - `packages/ui/src/components/tests/shadcn-compat.test.tsx` slipped
    through the file filter (its name contains `shadcn`). The ui reader
    read it anyway.
- **Tools:**
  - knip 6.43.0 (`pnpm knip`): `knip.json`, with `includeEntryExports`
    on and entries added for the hand-run CLIs and the type tests.
  - jscpd 5.4.2 (`pnpm dupes`): `.jscpd.json`, `minTokens` 60 and
    `minLines` 6, over api, back-office and every package except shadcn.
    It found 28 clones.
  - A tool hit counted only after a reader confirmed it in the code.
- **Readers and verifiers:**
  - 8 area readers each read every file in their area and returned
    findings plus an inventory: every helper, constant, type, component,
    stub and fixture, with its purpose.
  - A cross-package reader compared the inventories and the jscpd clones.
  - 9 verifiers, none of them the agent that raised the findings, re-read
    every finding at its `file:line`.
- **Outcome:** 163 findings raised, **155 kept**. The 8 dropped were taste,
  or wrong about the code.
  - 45 area findings recur in other areas and are listed once, under
    **Cross-package** or **Rules outdated**. Each area section names
    which ones.
  - Where a verifier corrected a fix, a size or a line, the correction is
    printed in the *fix* cell.
- **Yardstick:**
  - `rule: <doc>`: a written rule (AGENTS.md, `.claude/CLAUDE.md`,
    `docs/agents/*`, ADRs) and where it lives.
  - `judgement`: clean-code judgement where no rule speaks.
- **Size:**
  - **S**: one file, under an hour.
  - **M**: a few files, or one package.
  - **L**: crosses packages, or needs your decision.
