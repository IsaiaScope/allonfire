# The design package: shared Designs and Screens, managed by impeccable — design

**Date:** 2026-09-30
**Scope:** `packages/design` (new), `.claude/skills/aof-design` (new),
`.claude/skills/aof-documentation` (renamed from `doc-gen`), impeccable v4
installed per project, Back office wears the first Design (Japan) and its three
pages become Screens.
**Records:** ADR 0011 (supersedes ADR 0010's "one Theme per App");
CONTEXT.md gains **Design** and **Screen**, loses **Theme**.

## Intent

`packages/design` is the one place every App's interface is designed. It holds
the Designs (named visual worlds more than one App can wear; Japan first), each
App's product context and Screens, and all of impeccable's state. An App
imports one stylesheet and its Screens; its pages only route, fetch data and
translate. impeccable in all its commands is the tool for creating or editing
any page, and the `aof-design` skill is the only way in: it points impeccable at
the right App context inside the package, keeps the shared Design in step, and
hands impeccable the repo's rules. `doc-gen` becomes `aof-documentation` so the
repo's own skills share the `aof-` prefix.

## `packages/design`

```
packages/design/
  package.json            @allonfire/design; scripts design:sync, test, check-types
  README.md
  tsconfig.json
  vitest.config.ts
  .impeccable/
    config.json           committed (buildPath and the like)
    surfaces/             committed: per-Screen briefs and direction contracts
    critique/ mocks/ live/ config.local.json   gitignored
  scripts/
    sync.ts               CLI: design:sync [--check] [--from <app>]
    sync-core.ts          syncDesigns(root, options): pure over a repo root
    tests/sync.test.ts
  src/
    designs/japan/
      DESIGN.md           Google Stitch format, written by impeccable
      DESIGN.json         impeccable's sidecar (ramps, motion, snippets)
      theme.css           the tokens: :root, .dark, Tailwind v4 @theme inline
    apps/back-office/
      PRODUCT.md          who and why, written by impeccable init
      DESIGN.md           generated copy of the worn Design (header line)
      DESIGN.json         generated copy
      styles.css          @import ui base, the Design's theme.css; @source "./screens"
      screens/
        home.tsx          HomeScreen
        not-found.tsx     NotFoundScreen
        error.tsx         ErrorScreen ("use client")
        tests/            one render test per Screen
```

Exports, per App (Node allows one `*` per export key):
`"./apps/<app>/styles.css": "./src/apps/<app>/styles.css"`,
`"./apps/<app>/screens/*": "./src/apps/<app>/screens/*.tsx"`.
Dependencies: `@allonfire/ui` (workspace), peers `react`, `react-dom`.
The package is exempt from the Package Layout, like `ui`, `shadcn` and
`hooks`: it holds Designs and Apps, not features.
Root `package.json` gains `"design:sync": "pnpm --filter @allonfire/design design:sync"`.
Back office's `next.config.ts` adds `@allonfire/design` to `transpilePackages`.

### `design:sync`

`syncDesigns(root, { check, from })`, where `root` is the repo root:

1. **Map.** For each `packages/design/src/apps/<app>/styles.css`, match
   `@import "../../designs/<name>/theme.css"`. No match: that App is skipped.
   A `<name>` with no folder under `src/designs/` throws, naming App and name.
2. **Guard.** Throw if a `PRODUCT.md` or `DESIGN.md` (any case) exists at the
   repo root, in the repo's `docs/` or `.agents/context/`, or at the root of
   `packages/design`: impeccable would read it before `IMPECCABLE_CONTEXT_DIR`
   and brief the wrong App. Throw too if `packages/design/.impeccable/design.json`
   exists: impeccable prefers it over the App folder's `DESIGN.json`.
3. **Write (default).** For each mapped App: `src/apps/<app>/DESIGN.md` is the
   header line followed by the source file; `src/apps/<app>/DESIGN.json` is a
   copy. Header:
   `<!-- Generated from src/designs/<name>/DESIGN.md by design:sync. Edit through /aof-design. -->`.
   A Design without `DESIGN.json` removes the App copy.
4. **`--check`.** Write nothing; exit 1 listing every App file that is missing,
   stale, or present when it should not be.
5. **`--from <app>`.** Strip the header from the App's `DESIGN.md`, write it and
   the App's `DESIGN.json` to the Design's source, then step 3 for every App
   wearing that Design. An App wearing no Design throws.

## `aof-design` skill

`.claude/skills/aof-design/SKILL.md`, tracked.
Invocation: `/aof-design <command> [target] [--app <app>]`. `<command>` is any
impeccable command, or `new`.

**Every impeccable command:**

1. **App.** From `target` (a path under `apps/<app>/` or
   `packages/design/src/apps/<app>/`), else `--app`, else the only App folder
   in the package; ask when ambiguous.
2. **Design.** From that App's `styles.css`. None: stop, point at `new`.
3. **Sync in.** `pnpm design:sync`.
4. **Target in the package.** A named App file maps to its Screen
   (`apps/back-office/src/app/[locale]/page.tsx` to
   `packages/design/src/apps/back-office/screens/home.tsx`); no file means
   `packages/design/src/apps/<app>/`. Page-level work creates or edits a Screen,
   then wires the App page to render it with its `copy`.
5. **Hand off.** Invoke the `impeccable` skill with the command and
   `--target <package path>`. Every impeccable launcher call runs with
   `IMPECCABLE_CONTEXT_DIR=packages/design/src/apps/<app>`. The repo rules below
   precede the command.
6. **Tokens.** If `src/designs/<name>/theme.css` changed, run impeccable
   `document` (scan mode) against the App to refresh `DESIGN.md` and
   `DESIGN.json` from it.
7. **Sync out.** If the App's `DESIGN.md` or `DESIGN.json` changed,
   `pnpm design:sync --from <app>`; report which other Apps received it. If
   impeccable wrote `packages/design/.impeccable/design.json`, move it to the
   App's `DESIGN.json` first.
8. **Live cleanup.** After `live`, remove `apps/<app>/.impeccable/` and the repo
   root's `.impeccable/` if the session left them.

**Repo rules handed to impeccable:**

- Tokens change only in `packages/design/src/designs/<name>/theme.css`.
- Screens live in `packages/design/src/apps/<app>/screens/`, take copy as a
  typed `copy` prop and App elements as `ReactNode` slots, never import
  next-intl or the App. Server Components unless they need the client.
- Components come from `@allonfire/ui` (AOF components, `AOFButton` in
  `aof-button.tsx`). A missing one is created in `packages/ui`. Never edit
  `packages/shadcn`: a missing primitive is `npx shadcn@4.21.0 add <name>` from
  `apps/back-office`, then `pnpm --filter @allonfire/shadcn canonicalize`.
- Mobile-first; every image carries width and height.

**`new <name> --app <app>`:**

1. Create `src/designs/<name>/` and, if missing, `src/apps/<app>/` with a
   `styles.css` importing ui's base and `@source "./screens"`.
2. If the App folder has no real `PRODUCT.md`, run impeccable `init` there.
3. Run impeccable's new-work / `document` seed flow to write the App's
   `DESIGN.md` and `DESIGN.json`.
4. Write `theme.css` from the `DESIGN.md` frontmatter tokens, mapping them onto
   shadcn's variables (`--background`, `--primary`, ...) in `:root` and `.dark`.
5. Point the App's `styles.css` at the Design; `pnpm design:sync --from <app>`.

A different Design is worn by changing the one import in the App's
`styles.css`, then `pnpm design:sync`.

## Back office

- `globals.css` becomes the one design import plus `@source "../"`.
- `[locale]/page.tsx` translates `Home` and renders
  `<HomeScreen copy={{ title, description, action }} />`.
- `[locale]/not-found.tsx` renders
  `<NotFoundScreen copy={{ title }} back={<Link href="/">{t("back")}</Link>} />`.
- `[locale]/error.tsx` stays `"use client"` and renders
  `<ErrorScreen copy={{ title, retry }} onRetry={retry} />`.
- The layout, `providers.tsx` and i18n files stay in the App.

## Testing

- `packages/design/scripts/tests/sync.test.ts` (`// @module-tag unit`), a temp
  fixture repo per test: maps an App from `styles.css`; skips an App with no
  Design import; writes header plus body and the JSON copy; `--check` fails on a
  stale, missing and superfluous copy, naming the file; `--from` strips the
  header and fans out to a second App; unknown Design name throws; each guard
  path throws (root `PRODUCT.md`, `docs/DESIGN.md`, package-root `DESIGN.md`,
  `.impeccable/design.json`); a Design without `DESIGN.json` removes the copy.
- `screens/tests/*.test.tsx` (`unit`): each Screen renders its `copy`, its
  slot, and `ErrorScreen` calls `onRetry` on click.
- Back office's existing e2e still passes against the Screens.
- CI: `pnpm design:sync --check` in the `lint-types` job.

The Japan pass is the plan's last task and is interactive:
`/aof-design new japan --app back-office`. impeccable's interviews decide Back
office's `PRODUCT.md` and Japan's palette and type; this spec does not. It is
done when `pnpm --filter @allonfire/back-office build` compiles and
`pnpm design:sync --check` is clean.

## Unknowns settled while implementing

- impeccable's edit hook runs without `IMPECCABLE_CONTEXT_DIR` and reports
  cleanly ("No deterministic design-quality issues found").
- Live mode ignores `IMPECCABLE_CONTEXT_DIR` (`"error": "context_missing"`):
  it reads context only upward from the App. `aof-design` copies the App's
  `PRODUCT.md`/`DESIGN.md` into `apps/<app>/` for the session (gitignored) and
  removes them after. Its first boot also needs impeccable's live setup, which
  may extend the App's CSP; the skill asks before applying that. Whether
  `pageFiles` can name a Screen outside the App stays open until the first live
  session; the skill covers both outcomes.
